## 出典・著作権について（重要）

座席表画像は主に **LiveWalker（www.livewalker.com）/ ©MUSIC-MDATA** が作成したもので、
各画像に "このシステムはライブウォーカーが作成しました" のクレジットが入っている。
ヤンマースタジアム長居のみ、個人ブログ「Nico Lab」掲載の会場公式サイト転載画像を使用。

これらは**第三者が作成した著作物**であり、このリポジトリは GitHub Pages で公開される
パブリックリポジトリのため、そのまま `main` にマージしてサイトを公開すると
第三者の著作物を無断で再配布する形になる可能性がある。

- 開発時の**参考データ（アプリ内で独自に座席ブロックを描き直すための下敷き）**として利用し、
  画像そのものをアプリの配布物やWebサイトに含めないこと
- 座席ブロックの配置・番号・色分けなどの「事実情報」を参考に、アプリ独自のベクター画像
  （SVG等）として再構築するのが安全
- 本フォルダを `main` ブランチにマージ・公開する前に、ライセンス面を再確認すること
